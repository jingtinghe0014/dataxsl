# DataXSL 架构文档导航

原综合架构方案已于 2026-09-16 拆分为两份独立文档：

| 文档 | 入口与执行模型 | 内容重点 |
| --- | --- | --- |
| [多进程模型架构方案](architecture-multiprocess.md) | `main.py`：每通道 1 个读进程 + N 个写进程 | 当前执行链、插件、配置样例、问题清单及多通道演进 |
| [异步模型架构方案](architecture-async.md) | `main_async.py`：协程协调，每通道 1 个读线程 + N 个写线程 | 当前草稿缺口、线程与协程边界、队列、生命周期及实施计划 |

两份方案统一约定：`channel` 表示数据隔离的通道数，`parallel=N` 表示每通道的写入执行单元数，不包含读取单元。文件暂用单通道，数据库后续按主键或辅助键分片。

本文件保留为导航，详细架构以对应模型文档为准。
